## Overview
This experiment evaluated the impact of different text preprocessing strategies (`prep_default` vs `prep_minimal`) on the `baseline` model to determine if standard normalization or a less aggressive approach yields better results.

## Key Findings

1. **Performance Equivalence**: Both preprocessing strategies (`default` and `minimal`) yielded **identical performance metrics** across all evaluation criteria (MAE, Accuracy, F1 scores) when using the `baseline` model.
2. **Execution Time**: The execution time was marginally faster for the `minimal` preprocessing variant (133.4 seconds vs 134.3 seconds), though the difference is largely negligible and could be attributed to standard system variance.
3. **Model Sensitivity**: For the `baseline` model, altering the `XLMR_PREPROCESS_STRATEGY` configuration between `default` and `minimal` does not have any measurable impact on the downstream predictive performance. 

## Conclusion & Recommendations

1. **Use Minimal Preprocessing**: Since the metrics are identical, the `minimal` approach could be favored slightly due to its marginally faster runtime and simpler execution path, though either approach is perfectly acceptable for the `baseline` model.
2. **Further Testing on Neural Models**: While the `baseline` model is insensitive to these specific preprocessing variations, more complex models like `xlmr` might be much more sensitive to these textual nuances. Future sweeps should test these preprocessing variants explicitly on transformer-based architectures.
