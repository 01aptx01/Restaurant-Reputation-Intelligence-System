## Key Findings

1. **Preprocessing Impact**: The strategies `b1_preprocess_default` and `b4_preprocess_keep_digits` performed slightly better in terms of MAE compared to the rest.
2. **Model Robustness**: Most of the variants (including different base embedding models and classifiers) produced very similar or identical MAE and Accuracy. This suggests that the current pipeline might not be fully leveraging the representational differences between models, or the dataset limits the variance.
3. **Missing Dependencies**: Fine-tuning attempts (`e1_finetune_supervised` and `f2_best_combo_e5_finetune`) failed due to a missing `datasets` dependency.

## Conclusion & Recommendations

1. **Install Dependencies**: Install the `datasets` package to successfully run the fine-tuning experiments and evaluate their true potential.
2. **Review Embedding Integration**: Given that many distinct embedding models (E5, BGE, MiniLM) yielded identical metrics to the production baseline, we should verify that the pipeline is correctly routing and applying these embeddings instead of a fallback mechanism.
3. **Adopt Best Preprocessing**: Consider adopting `preprocess_default` or `keep_digits` as they yielded slightly lower MAE.
