# Real-world Evaluation Limits for Review Score Prediction

เอกสารนี้สรุปข้อจำกัดและประสิทธิภาพที่เป็นไปได้ในโลกความเป็นจริง สำหรับงานทำนายคะแนนดาว (1-5 ดาว) จากข้อความรีวิว โดยอ้างอิงจากค่า **MAE (Mean Absolute Error)** ซึ่งเป็นเกณฑ์การประเมินหลัก (ยิ่งค่าน้อยยิ่งดี)

## 1. เพดานสูงสุดที่เป็นไปได้ (Human-Level Limit)
- **MAE ที่คาดหวัง:** `0.20 - 0.30`
- **เหตุผล:** ในโลกความเป็นจริง MAE จะไม่มีทางเป็น 0.0 ได้เลย เนื่องจากความขัดแย้งของข้อมูลที่เกิดจากมนุษย์ (Subjectivity & Noise) เช่น:
  - การพิมพ์คำชมเหมือนกัน แต่ผู้ใช้ต่างคนต่างให้ดาวไม่เท่ากัน (บางคนให้ 4 ดาว บางคนให้ 5 ดาว)
  - การกดดาวผิดพลาด (พิมพ์ด่าแต่ให้ 5 ดาว)
  - งานวิจัยทาง NLP ระบุว่า เมื่อให้มนุษย์ 2 คนมาอ่านข้อความเดียวกันเพื่อเดาคะแนนดาว มักจะมีความคลาดเคลื่อนกันเองอยู่ที่ระดับ MAE 0.20 ถึง 0.30 ดังนั้นนี่คือ **"เพดานที่เป็นไปได้สูงสุด (Upper Bound)"** ของ AI ในงานนี้

## 2. ระดับดีเยี่ยม / ระดับโลก (State-of-the-Art / SOTA)
- **MAE ที่คาดหวัง:** `0.30 - 0.45`
- **เหตุผล:** เป็นจุดที่โมเดลภาษาขนาดใหญ่ที่ทันสมัย (เช่น BERT, RoBERTa, LLMs) สามารถทำได้เมื่อผ่านการ Fine-tuning อย่างเหมาะสม โมเดลกลุ่มนี้มีความสามารถในการทำความเข้าใจบริบท การประชดประชัน และอารมณ์ที่ซับซ้อนได้ใกล้เคียงกับมนุษย์
- **หมายเหตุ:** โปรเจกต์นี้สามารถทำ MAE ได้ที่ `0.3155` (ด้วยโมเดล XLM-RoBERTa) ซึ่งถือว่าอยู่ในระดับ State-of-the-Art และชนเพดานของ Human-Level Limit แล้ว

## 3. ระดับใช้งานได้ทั่วไป (Standard / Traditional ML)
- **MAE ที่คาดหวัง:** `0.50 - 0.80`
- **เหตุผล:** ประสิทธิภาพเฉลี่ยของโมเดล Machine Learning แบบดั้งเดิม (เช่น TF-IDF ร่วมกับ Logistic Regression, SVM, หรือ XGBoost) โมเดลสามารถแยกแยะความรู้สึกเชิงบวกและลบได้ดี แต่อาจไม่ละเอียดพอที่จะแยกความแตกต่างระหว่าง 4 กับ 5 ดาว หรือ 1 กับ 2 ดาว ทำให้เกิดความคลาดเคลื่อนประมาณครึ่งดาวถึงเกือบหนึ่งดาว

## 4. ขั้นต่ำสุด / แย่ที่สุด (Naïve Baseline / Worst Case)
- **MAE ที่คาดหวัง:** `0.90 - 1.30`
- **เหตุผล:** คือการที่โมเดลแทบไม่มีการเรียนรู้อะไรจากข้อความรีวิวเลย เช่น การเดาจากค่าเฉลี่ยของข้อมูล (เดา 4 ดาวทุกครั้ง) หรือการสุ่มเดา 
- หากโมเดลใดๆ ได้ค่า MAE เกิน 0.90 ถือเป็นเส้นตายที่แสดงว่าโมเดลนั้นอาจทำงานผิดพลาดหรือไม่มีประสิทธิภาพในการทำนายเลย
