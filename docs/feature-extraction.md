# Feature Extraction (การสกัดคุณลักษณะ)

เอกสารนี้อธิบายถึงเทคนิคและค่าพารามิเตอร์ต่างๆ ที่ใช้ในการแปลงข้อความรีวิวให้เป็นข้อมูลตัวเลข (Feature Extraction) ภายในโปรเจค Restaurant-Reputation-Intelligence-System (อ้างอิงจาก `rris/config.py` และ `rris/data/text.py`)

---

## 1. การสกัดด้วย TF-IDF สำหรับ Baseline Model

สำหรับโมเดลกลุ่ม Sklearn และ XGBoost จะใช้เทคนิค Bag-of-Words ร่วมกับการถ่วงน้ำหนักความถี่ TF-IDF (Term Frequency-Inverse Document Frequency) โดยประยุกต์ใช้ 2 ระดับ:

### 1.1 Word-level TF-IDF (ระดับคำศัพท์)
- **เครื่องมือการตัดคำ:** ใช้ไลบรารี `PyThaiNLP` (engine `newmm`)
- **ขนาด Features:** กำหนดไว้สูงสุดที่ **8,000 คำศัพท์เด่น** (`TFIDF_MAX_FEATURES = 8000`)
- **N-gram Range:** ครอบคลุมทั้งคำเดี่ยว (Unigram) และกลุ่มคำ 2 คำ (Bigram) ควบคู่กันไป เช่น มองทั้ง "บริการ" และ "บริการ แย่" (`TFIDF_NGRAM_RANGE = (1, 2)`)
- **การกรอง Noise:**
  - `min_df=2`: กรองคำที่โผล่มาแค่ 1 ครั้งทิ้ง เพื่อลด Noise จากการพิมพ์ผิด
  - `max_df=0.9`: กรองคำที่ปรากฏมากกว่า 90% ของชุดข้อมูลทิ้ง (ทำหน้าที่คล้าย Stop words ถาวร)

### 1.2 Character-level TF-IDF (ระดับตัวอักษร)
ฟีเจอร์นี้เปิดไว้เพื่อรองรับการสะกดคำผิดในภาษาไทยหรือคำแสลงใหม่ๆ (`BASELINE_USE_CHAR_TFIDF = True`)
- **N-gram Range:** หั่นตัวอักษรตั้งแต่ 3 ถึง 5 ตัวอักษร (`BASELINE_CHAR_NGRAM_RANGE = (3, 5)`)
- **ขอบเขต:** จำกัดให้อยู่ในขอบเขตของแต่ละคำเท่านั้น (`analyzer="char_wb"`)
- **ขนาด Features:** สกัดรูปพยางค์หรือกลุ่มตัวอักษรสูงสุดที่ **4,000 มิติ** (`BASELINE_CHAR_MAX_FEATURES = 4000`)

เมื่อรวมฟีเจอร์ Word และ Char เข้าด้วยกัน จะได้ Sparse Matrix ที่มีมิติกว่า 12,000 แกน

## 2. ฟีเจอร์โครงสร้างทางภาษา (Extra Linguistic Features)

นอกจากการนับคำแล้ว โปรแกรมยังวิเคราะห์โครงสร้างโดยรวมของประโยคเพื่อสร้างเป็นฟีเจอร์ตัวเลขเพิ่มเติม (ดูที่ `rris/data/features.py`)

- **การแปล Emoji และ Slang (Pre-extraction):** แปลงอีโมจิและคำสแลงกลับเป็นคำไทยมาตรฐานก่อน เช่น `😡` → "โกรธ", `"ดรอป"` → "คุณภาพแย่ลง" (ใน `text.py`) ช่วยให้ TF-IDF สามารถนับกลุ่มคำเหล่านั้นเข้าพวกได้ดีขึ้น
- **Character Length:** นับจำนวนตัวอักษรรวม (โดยตัดทอนความยาวไว้ที่ 500 ตัวอักษร)
- **Word Count:** นับจำนวนคำศัพท์รวมในรีวิว (ตัดด้วย `PyThaiNLP`)
- **Negation Count (การนับคำปฏิเสธ):** ค้นหาและนับวลีที่เป็นคำปฏิเสธโดยเฉพาะ ได้แก่ `"ไม่แนะนำ"`, `"ไม่ค่อย"`, และ `"ไม่"` เนื่องจากฟีเจอร์เหล่านี้ส่งผลกระทบเชิงลบโดยตรงต่อคะแนนดาวของรีวิวอย่างมาก

---

## 3. การลดมิติข้อมูลด้วย LSA (Latent Semantic Analysis)

กระบวนการนี้เป็นออปชั่นเสริมที่ใช้ `TruncatedSVD` สำหรับบีบอัดแกนมิติของ TF-IDF (กว่า 12,000 มิติ) ให้เล็กลง เหลือเพียงหัวข้อหลัก (Latent Topics)
- **จำนวนมิติเป้าหมาย:** กำหนดไว้ที่ **400 มิติ** (`LSA_N_COMPONENTS = 400`)
- **สถานะปัจจุบัน:** *ถูกปิดการใช้งาน* (`BASELINE_USE_LSA = False`) เนื่องจากการทดสอบเชิงลึก (Ablation Study) พบว่าการป้อนข้อมูล Sparse Matrix เต็มรูปแบบให้กับ XGBoost สามารถให้ผลลัพธ์การทำนายคะแนนดาวได้แม่นยำกว่าการลดทอนมิติ

---

## 4. เวกเตอร์ความหมายเชิงลึก (Deep Dense Embeddings)

ส่วนนี้ใช้ในการทดลองขั้นสูง (Advanced Modeling) โดยใช้สถาปัตยกรรมกลุ่ม Transformer ที่ไม่ต้องอาศัยการตัดคำแยกทีละคำเหมือน PyThaiNLP แต่วิเคราะห์ลำดับและบริบทแบบสองทิศทาง

### 4.1 Sentence Embedding Models
- **Models:** `intfloat/multilingual-e5-base` หรือ `BAAI/bge-m3`
- **วิธีการ:** แปลงข้อความความยาวสูงสุด 128 โทเคน (`EMBEDDING_MAX_LENGTH = 128`) ให้เป็นเวกเตอร์ฝังตัว (Dense Vector) 1 ชุดที่มีความหมายสรุปของทั้งประโยค
- สามารถนำเวกเตอร์นี้ไปป้อนให้ Classifier ทั่วไป (เช่น Logistic Regression หรือ XGBoost) เพื่อทำนายผลได้เลย

### 4.2 XLM-RoBERTa (Fine-Tuning)
- **Models:** `xlm-roberta-base` (125M params) หรือ `xlm-roberta-large` (355M params)
- **วิธีการ:** ใช้ SentencePiece Tokenizer ทำการหั่นโทเคน
- ข้อมูลจะไหลผ่าน Attention Layers เพื่อสร้าง Contextualized Representation จากนั้นดึงฟีเจอร์บริเวณตำแหน่งของ `[CLS]` (หรือเริ่มประโยค) ป้อนเข้าสู่ Classification Head พร้อมคำนวณ Regression Loss / Focal Loss เพื่ออัปเดตน้ำหนักของพารามิเตอร์โดยตรง
